# DecoNova hackathon MVP

AI interior makeover: photograph a room, pick one of 32 styles, get a realistic redesign, a budget-capped shopping plan, Vastu notes and a share-and-vote link for the family.

**Live demo:** https://stirring-piroshki-b4494b.netlify.app (sign in with Google)

Free-tier build of the DecoNova spec. One static web page (also installable as a phone app), a free Supabase project, and a Gemini API key. Built by porting `deconova.html`; only the render step and storage changed.

## What works

| Feature | Demo mode (no setup) | Connected mode |
| --- | --- | --- |
| Sign in | Any email, data stays in this browser | Google sign-in (email magic link also works, but Supabase's built-in email is rate-limited), per-user rows locked by row-level security |
| Room Read, Design Story | Built-in fallback text | Claude Haiku vision and text (Gemini fallback if no Anthropic key) |
| Makeover render | Simulated preview | Real image model, 32 styles, 7 "Who lives here" packs |
| Edit tab: floor swap, remove an object, furnish an empty room | Explains what is needed | One render each |
| Budget Mode (₹ budget, plan kept under it) | Needs connection | Claude text; the total is checked in code, not trusted from the model |
| Shop the Look (search links on every item) | Yes | Yes |
| Vastu notes (movable changes only) | Needs connection | Claude text |
| Share link and family vote | Needs connection | Private link, expires in 30 days, owner can stop it, one vote per browser |
| Reveal slider, wall colour, contrast gate, light, versions, gallery, read-only saved rooms | Yes | Yes |
| Layout match score (structure lock check) | n/a | Shown after every real render |
| Credits, idempotency, hard spend cap | n/a | Enforced in the database, not the browser |
| Android | n/a | Installable PWA; APK via PWABuilder (see GUIDE_FOR_NON_CODERS.md) |

Not in this MVP: exterior mode, brush masks for removal, payments, a native Android codebase.

## Set it up

Non-coders: follow `GUIDE_FOR_NON_CODERS.md`. Developers: run both SQL files in `supabase/migrations/`, deploy the functions in `supabase/functions` (or paste the bundles from `supabase/dist/`), set secrets `GEMINI_API_KEY` (image renders), `ANTHROPIC_API_KEY` (text and vision, optional; Gemini is used if absent), `MAX_TOTAL_RENDERS`, and optionally `CLAUDE_MODEL` / `GEMINI_TEXT_MODEL` / `GEMINI_IMAGE_MODEL`, fill `web/config.js`, and host `web/` on any static host. Regenerate the bundles with esbuild after editing a function.
After editing `scripts/extra_styles.json`, run `python3 -I scripts/build_styles.py ../deconova-build-spec.md` from this folder.

## What it costs

| Item | Cost |
| --- | --- |
| Supabase free plan, Netlify or Cloudflare free hosting | ₹0 |
| Claude Haiku text and vision (room read, story, budget, Vastu) | About ₹1 to ₹2 per call (Anthropic API, prepaid) |
| Image renders | About ₹3 to ₹4 each at the draft-tier price (US$0.0336 per 1K image, 13 Oct 2026), plus a small input charge |
| Hard ceiling | `MAX_TOTAL_RENDERS=300`, so roughly ₹900 to ₹1,200 at most. After that the app shows the simulated preview |

Check the live price before the demo. Free-tier Gemini requests may be used by Google to improve its products, so use sample rooms, not private photos, until you move to a paid key.

## Folder map

- `web/` the app (`index.html`, `config.js`, PWA files)
- `supabase/migrations/` tables, row-level security, credit functions
- `supabase/functions/ai` room read, story, budget, Vastu; `generate` restyle, floor, remove, stage
- `supabase/dist/` the same two functions bundled into single paste-ready files
- `web/share.html` the public family-vote page
- `supabase/functions/_shared/catalog.ts` is generated by `scripts/build_styles.py` (12 spec styles plus 20 in `scripts/extra_styles.json`)

## Known limits

- Rooms are stored as small JPEG thumbnails in a private key-value table, not in Storage buckets. Fine for a demo; move to buckets with signed URLs for production (spec section 17).
- Wall repaint is the prototype's free client-side blend, not a model render.
- The layout-match threshold (50%) is untuned. Calibrate it on 50 real photos.
- Verified live on 30 Oct 2026: Google sign-in, all four text tasks (5 to 14 s), and one real render (about 21 s). Share link and family vote, and the Android PWABuilder path, have not been tested end to end.
- Gemini text models were slow or overloaded for new keys in October 2026, which is why text and vision moved to Claude; image generation stays on Gemini (needs a billed Google project).
- The store screenshots (`shot-1.png`, `shot-2.png`) use a synthetic test room. Replace them with real ones before a Play Store listing.
- Family-vote photos are stored in the database as 760 px JPEGs, so keep shares to a few designs on the free 500 MB plan.
